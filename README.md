# AI Notes Assistant

## 📖 Overview

AI Notes Assistant is a web application that helps students and learners quickly understand study materials by generating concise summaries and multiple-choice questions (MCQs) using Artificial Intelligence. The application simplifies learning by converting lengthy notes into easy-to-understand content and interactive quizzes.

---

## ✨ Features

- 📄 Upload or paste study notes
- 🤖 AI-powered text summarization
- ❓ Automatic MCQ generation
- 📚 Easy-to-use web interface
- ⚡ Fast response using Generative AI
- 💻 Responsive and user-friendly design



